🔗 Google Sheets – Sinkronisasi Data Langsung ● TERSAMBUNG
Langkah 1 — Masukkan URL Google Apps Script Web App
URL boleh disimpan dalam penyemak imbas anda – ia akan diingat semasa sesi ini.
Belum disinkronkan.
📖 Panduan Persediaan Google Apps Script (klik untuk buka)
Langkah-langkah persediaan:
  1. Buka Google Sheets anda → Extensions → Apps Script
  2. Padam kod sedia ada, kemudian tampal kod berikut:
function doGet(e) {
  const type  = (e.parameter.type || 'programmes');
  const sheet = SpreadsheetApp.getActiveSpreadsheet()
                  .getSheetByName(type);   // sheet tab must match type name
  if (!sheet) return jsonOut({ error: 'Sheet "' + type + '" not found' });

  const rows   = sheet.getDataRange().getValues();
  const header = rows[0];
  const data   = rows.slice(1).map(r =>
    header.reduce((obj, h, i) => { obj[h] = r[i]; return obj; }, {})
  );
  return jsonOut({ type: type, data: data });
}

function jsonOut(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
